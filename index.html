Publications

Lightweight segmentation model for automated facade installation in high-rise buildings

A lightweight attention network that segments curtain wall module frames so a robot can find installation locations on high-rise buildings. MBConv stages, an efficient transformer and channel attention modules keep it fast enough for real-time use on site. Published in Advanced Engineering Informatics, 2025.

  • Semantic segmentation
  • Transformer
  • Construction robotics

Lightweight vision-based 6D pose estimation of curtain wall module installation slot

A two-stage pipeline for locating where a curtain wall module goes. LANet segments the scene, corners are extracted with a rule-based algorithm, and a PnP solver estimates the pose of a reference panel, which is propagated to the target installation slot.

  • 6D pose estimation
  • PnP
  • Construction robotics
